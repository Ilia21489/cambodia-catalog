# Каталог новостроек — Best of Cambodia Property

Telegram Mini App с каталогом проектов агентства Baza Nova.

- `index.html`, `app.js`, `app.css` — само приложение (статический сайт на GitHub Pages)
- `data/projects.json`, `assets/` — данные и картинки, выгруженные из Buildin

Обновить каталог из Buildin:

```bash
.venv/bin/python scripts/export.py
```
